## 🌟 Overview

University life involves balancing academics, personal projects, deadlines, extracurricular activities, and professional growth. Managing these responsibilities across multiple platforms can become overwhelming.

**Uni-Verse aims to simplify this experience** by providing a unified digital space where students can organize their work, collaborate with peers, showcase their achievements, and explore AI-powered productivity features.

Whether you are working on a college assignment, building a project, learning a new skill, or connecting with fellow students, Uni-Verse is designed to make your academic journey more organized and collaborative.

### 🎯 Our Mission

To create a connected student ecosystem that makes academic life more productive, collaborative, and engaging.

## 🚀 Getting Started

Follow these steps to run Uni-Verse locally.

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/) — compatible with Next.js 14.
- npm — included with Node.js.
- [Git](https://git-scm.com/) — for cloning the repository.

### 1. Clone the Repository

```bash
git clone https://github.com/prshnt-4/Uni-Verse.git
```

### 2. Navigate to the Project Directory

```bash
cd Uni-Verse
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

### 5. Open the Application

Visit the following URL in your browser:

```text
http://localhost:3000
```

You should now be able to explore the application locally.
